# Medright Medical Network Guide

Filterable directory of the Medright medical network (hospitals, labs, pharmacies, doctors, dentists, x-ray, physiotherapy, optics, hearing aids) across Egypt.

Filter by plan (Elite / Premium / Classic / Regular / Basic), provider type, city, area and specialty.

## Update the data

```bash
python3 build.py "/path/to/Medical Network Guide.xlsx"
git commit -am "update data" && git push
```
